# Synkora Group - Site web

Ce dossier contient le site vitrine statique de Synkora Group, publié sur GitHub Pages et conçu pour présenter l'écosystème, les plateformes, la direction produit, les actualités et le contact.

## Contenu

- `index.html` : page principale du site.
- `css/styles.css` : design, responsive et charte visuelle.
- `js/app.js` : menu mobile, animations légères et formulaire email.
- `assets/` : logo SVG, favicon, icônes PWA et logo PNG.
- `site.webmanifest`, `service-worker.js`, `offline.html` : base PWA.
- `robots.txt`, `sitemap.xml` : indexation et référencement.
- `docs/cahier-des-charges-synkora-group.docx` : cahier des charges éditable.

## Utilisation rapide

Ouvrir `index.html` dans un navigateur ou lancer un serveur statique local.

## Sections du site

- Accueil
- Plateformes : BuildSync AI, BizPocket, Devis BTP, StudyNK, Lodpam, futurs projets
- Activités
- Pôles
- Direction produit
- Actualités
- Contact

## À finaliser avec des informations officielles

- Domaine officiel si Synkora Group veut quitter l'URL GitHub Pages.
- Coordonnées vérifiées : téléphone, adresse, WhatsApp et réseaux sociaux seulement quand ils sont réels.
- Membres de l'équipe, rôles, photos et biographies seulement après validation.
- Informations administratives complètes dans les mentions légales avant usage commercial officiel.
- Formulaire connecté à un vrai serveur ou outil d'emailing si vous voulez recevoir les demandes sans passer par `mailto:`.

## Mise en ligne

Le site est statique. Il est compatible avec GitHub Pages, Netlify, Vercel, un hébergement mutualisé ou un serveur classique.
